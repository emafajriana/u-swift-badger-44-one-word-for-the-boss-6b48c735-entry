## The word

**Backseater** — the boss who drives from the back seat, steering every task from over your shoulder. Funny on its own, true of a real boss habit, and it travels from an office to a kitchen to a warehouse.

## Run

```sh
python3 main.py
```

Writes the single word to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`), verifying the 1–30 character gate before writing and the written bytes afterwards. Standard library only.
